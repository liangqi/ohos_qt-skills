## How to become a contributor

1. Clone this repository
2. For environment initialization, see `skills/kb-init/SKILL.md` (detects DevEco/SDK/Qt and generates `ENV.local.md`)
3. Submit a PR following [CONTRIBUTING.md](../CONTRIBUTING.md)
4. Once your PR is merged, your name will appear in this list
