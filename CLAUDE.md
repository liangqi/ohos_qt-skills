# CLAUDE.md

This file tells AI tools (Claude Code / Codex / Cursor and the like) how to use this knowledge base.

> **This is a reference knowledge base for porting Qt to HarmonyOS**, aimed at developers porting Qt applications to HarmonyOS and analyzing Qt application problems.
> It is generated by trimming and sanitizing a larger personal workflow knowledge base (see `_scripts/kb-dev-edition.sh`).

---

## First use (required reading for agents)

If this is the user's first time using this knowledge base, or `ENV.local.md` doesn't exist, you **must** run `skills/kb-init/SKILL.md` first to complete initialization.

The initialization skill walks the user through:
- Detecting the current environment (DevEco Studio, HarmonyOS SDK, Qt source, and so on)
- Guiding installation of missing dependencies
- Generating `ENV.local.md` (local path configuration)
- Validating that the environment works

**Trigger keywords**: automatically run the initialization skill when the user says "initialize", "configure the environment", "first time using this", or "ENV.local.md doesn't exist".

**Once you receive a task, load in this order**:

```

② _index/_task-routing.md    → match the task type and determine the workflow and required pages
③ semantic/qt-harmonyos-golden-rules.md  → scan the 35 iron rules (to avoid known pitfalls)
④ _index/_map.md             → the knowledge map; judge relevance from the summaries
⑤ Read only the relevant knowledge pages → don't load everything
⑥ Follow the refs field for cross-references → for deeper context
```

## Reading conventions

- **summary**: the one-sentence summary in each page's frontmatter; agents use it to decide whether to load the page
- **refs**: ids of cross-referenced knowledge pages; follow them for deeper context
- **tags**: browse by topic through `_index/_tags.md`
- **problems/ records real execution errors** (build failures, deployment failures, runtime crashes), not platform limitations from the Qt documentation — those live in `semantic/qt-harmonyos-platform-limits.md`

## Path variables

Knowledge pages refer to local paths by variable name (such as `QT5_15_SRC`, `OHOS_SDK_NATIVE`) rather than hard-coding them. The actual values live in `ENV.local.md` (generated by `skills/kb-init/`, or created by hand).

## Embedded general HarmonyOS platform knowledge

This knowledge base embeds the `ohos-common-kb-public/` directory, containing general HarmonyOS platform knowledge (ArkTS, ArkUI, NAPI, the Stage model, the DevEco toolchain, and so on). When a task concerns platform mechanics rather than Qt-specific problems, consult that directory first.
